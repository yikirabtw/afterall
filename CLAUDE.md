# Проект: тиммейты и компании на вечер (Telegram-бот + мини-приложение)

Рабочее название пока не выбрано. Идея: «не свайпай людей, а собери пати на сегодня».
Пользователь находит тиммейтов для игр или компанию на вечер через бота и мини-приложение в Telegram.

## Документы
- `docs/ROADMAP.md` — дорожная карта по этапам (источник правды по плану работ).
- `docs/DATABASE.md` — описание таблиц и принципов схемы.

## Стек
- Бэкенд: Python 3.13, SQLAlchemy 2.1, Alembic. Код в `backend/`.
- API: FastAPI, код в `backend/app/api/`, запуск `python -m app.api` из `backend/` (порт 8000, `/docs`).
  Все маршруты под `/api`. Вход — заголовок `Authorization: tma <initData>` на каждый запрос,
  проверка в `api/telegram_auth.py` (подпись через aiogram + свой контроль срока), зависимость
  `CurrentUser` в `api/deps.py`. Коммиты в базу — явные (`await session.commit()`), не в зависимости.
  Приложение собирается через `create_app(...)` с параметрами — тесты передают свою базу и токен.
  Онбординг — `api/routes/onboarding.py`: отдельные PUT на каждый шаг (они же для редактирования профиля)
  + `POST /me/onboarding/complete`. Каждый возвращает `MeOut` через `load_me`.
  Правила: дата рождения задаётся один раз; младше MIN_AGE — ничего не сохраняем;
  аватар по ссылке не принимаем (будет загрузка с модерацией).
  Тестовые помощники подписи initData — `tests/initdata.py`, фикстура `client` — в `tests/conftest.py`.
  Пати — `api/routes/lobbies.py`; кто что видит (контакты, участники) — только в `api/lobby_views.py`;
  константы и правила (срок жизни, лимиты, ранги) — `domain/lobbies.py`. Доступ к пати — `OnboardedUser`.
  Время: в базе всегда UTC, SQLite отдаёт его без пояса — сравнивать через `domain/time.as_utc`,
  в ответах использовать тип `UtcDatetime`.
- Не трогать реальную запись пользователя в dev.db при живых проверках (дата рождения необратима) —
  использовать временного тестового пользователя и удалять его после.
- Бот: aiogram 3, код в `backend/app/bot/`, запуск `python -m app.bot` из `backend/`.
  Роутеры создаются фабриками `create_router()` (роутер aiogram подключается только один раз,
  а тесты собирают диспетчер заново). Тексты — только в `bot/texts.py`.
  Бот и API работают с базой асинхронно (`AsyncSessionLocal`), скрипты и миграции — синхронно.
- Общая логика для бота и API — в `backend/app/services/` (например, регистрация пользователя).
- Тесты: `python -m pytest -q` из `backend/`. Бот тестируется целиком через `dispatcher.feed_update`
  с подменённой сетевой сессией (`tests/test_bot.py`).
- Мини-приложение: Vue 3 + Vite + TypeScript в `webapp/` (Node.js 24 LTS установлен; в новых окнах
  PowerShell PATH к node может быть не обновлён — подставлять `$env:Path` из Machine+User).
  Без UI-библиотек: общие стили и токены — `src/styles.css`. Визуал — см. «Визуал» ниже (тёмный монохром, тему Telegram не повторяем).
  Состояние — `stores/session.ts` (reactive), роутер на memory history (в #-части URL Telegram передаёт initData).
  Тексты ошибок API — `src/api/errors.ts`, подписи значений — `src/labels.ts`. Типы `src/api/types.ts`
  повторяют схемы бэкенда — менять вместе.
  Разработка в браузере: `scripts/dev_init_data.py` пишет вход тестового `dev_tester` в
  `webapp/.env.development.local`; dev-сервер слушает 127.0.0.1:5173 и проксирует `/api` на 8000.
  Панель браузера Claude читает `.claude/launch.json` из исходной папки сессии (scratch), не из проекта.
  В эмуляции телефона клики по координатам в панели смещаются — нажимать элементы через JS.
- БД: локально SQLite (`backend/dev.db`), в продакшене PostgreSQL. Переключение — через `DATABASE_URL` в `backend/.env`.
- Git установлен (2.56), репозиторий в корне проекта, ветка `main`; Docker не установлен.
  Сообщения коммитов на русском — передавать через файл в `.git/` (у PowerShell 5.1 и длинных путей temp проблемы).
- Хостинг (решение пользователя: бесплатно, пока нет потока людей и продаж подписок): Render (free, Frankfurt,
  Docker из `Dockerfile` + `render.yaml`) + Neon (free Postgres). На сервере бот — вебхук внутри API
  (`TelegramWebhook` в `api/main.py`, маршрут `api/routes/telegram.py`), включается, когда есть `PUBLIC_URL`
  или `RENDER_EXTERNAL_URL`. Локально `PUBLIC_URL` НЕ задавать — иначе настоящий бот переключится на вебхук.
  Туннели Cloudflare на сети пользователя заблокированы (и с его VPN тоже) — не предлагать.
  Платный сервер — потом, вне России (Telegram API с российских IP работает плохо).
- Рабочее имя бота и приложения — afterall (@afterall67_bot).

## Принятые решения (не пересматривать без пользователя)
- Аудитория во многом школьники — не отрезаем, а делаем продукт безопасным по умолчанию:
  возрастные группы (13–15, 16–17, 18+), подбор только внутри своей группы,
  контакт только после взаимного отклика/мэтча, без точной геолокации (только город),
  личные фото не обязательны. Окончательное решение по возрасту — позже.
- Никаких лутбоксов, сундуков и рандомных наград. Удержание — через реальную игру с людьми:
  стрик команды, «Вечер сегодня», недельный итог, сезонный пасс за активность, соцквесты.
- Честные цены и подписки, без «1 ₽ с автопродлением мелким шрифтом».
- Права модераторов всегда проверяются на сервере.
- Свой дизайн, не копия ashqua (её разбирали как референс).

## Визуал (28.10.2026, выложено на сервер)
Референсы — папка `визуал/` в корне (пользователь: шаблоны и фото брать только оттуда; в git её не кладём — 23 МБ).
По ним: полный визуал — сайт EX8 (чёрный, пиксельные заголовки, пунктирные разделители, каркасные кубы),
палитра — шкала Dark `#000 → #FAFAFA`, свечение белое (ступени blur 8/32/128) + свет «сверху» (лампа, полоса над карточкой),
цвет — только точечно и со свечением (шпаргалка цветов): полоска цвета игры у пати (`lobby.ts: gameColor`), статусы ok/warn/danger.
- Токены — `styles.css` (`--g-*`, `--glow-*`, `.card--lit`, `.empty` с полосой света, `.dots-loader`). Мятного акцента больше нет: акцент белый.
- Темы: тёмная по умолчанию и светлая (шкала Light) — переключатель в профиле → «Ещё», хранится в localStorage
  (`stores/theme.ts`, атрибут `data-theme` на `<html>`, шапка Telegram красится под тему). Свечение писать через
  `rgb(var(--glow-rgb) / …)`, полосы «лампы» — `var(--lamp)`; белый `#fff` — только поверх фото.
  `.theme-dark` держит тёмную тему внутри светлой (заставка, экран мэтча).
- Анимация переключателей — директива `v-jelly` (`src/jelly.ts`): механика JellyRadio из React Bits, перенесённая
  на Vue без библиотек (свои пружины). Нижняя панель — `v-jelly="TAB_JELLY"`, тема — `v-jelly="{ room: true }"`,
  все `.segmented` — `v-jelly.soft`. Выбранный ребёнок определяется по aria-pressed/aria-checked/router-link-active.
- «Расплытие» — `src/reveal.ts` (View Transitions API, круг из точки + размытие; CSS в конце `styles.css`):
  карандаш открывает `/profile/edit` из своей точки, `goBack()` сворачивает обратно (`rememberOrigin`/`takeOrigin`);
  смена темы разливается от нажатой кнопки. Без API — смена без анимации. `.rise-in` — подъём блоков экрана по очереди.
- Смена вкладок (Пати/Лента/Профиль) — `<Transition>` в `HomeLayout.vue`: еле заметный сдвиг 12px + проявление
  из лёгкого размытия, направление — по порядку вкладок. Нижние шторки (выбор игры, фильтры) — `<Transition name="sheet"
  :duration="SHEET_MS">` (`src/sheet.ts`, CSS в `styles.css` → «Нижняя шторка»): поднимаются снизу из размытия.
- Панель браузера Claude, когда скрыта, замораживает CSS-анимации (таймлайн стоит) — проверять кадры, только когда она видна.
- «Расплытие» бывает двух форм (`reveal.ts`): `circle` — карандаш, тема; `morph` — кнопка «Создать» растягивается
  в экран `/create`. Открывать через `openFrom(el, path, shape)` из `router.ts`, назад — обычный `goBack()`.
- Карточки пати — «металл» (`v-reflect`, `src/reflect.ts`, по мотивам ReflectiveCard): размытое отражение
  `assets/reflection.jpg` (из «полосы света» в папке) едет при прокрутке, наклон ±3° и блик от пальца/курсора.
- Тумблеры `.switch` — растяжение кружка при переключении (по мотивам SquishSwitch), включается после первого
  переключения (`src/squish.ts` → класс `switch--live`).
- В dev.db сейчас локальные демо-боты (4 шт., переведены в группу 16_17, чтобы их видел `dev_tester`) и 7 их пати —
  для проверки визуала. Убрать: удалить пользователей `demo_%` (каскадом уйдут пати и анкеты).
- `components/BorderGlow.vue` — светящаяся рамка (по мотивам BorderGlow из React Bits): мышью — у ближнего края,
  пальцем — в сторону касания. Цвет — `var(--lamp)` (пользователь: без цветного градиента — белая в тёмной теме,
  чёрная в светлой). Сейчас на карточках профиля (о себе, игры, «Ещё»).
- Шрифты (@fontsource, самохостинг): Tiny5 — пиксельные заголовки экранов и цифры; Tektur — подписи и кнопки КАПСОМ;
  Russo One — заголовки в обычном регистре (у Tektur строчная «д» похожа на «g»); Metal Mania — только логотип заставки.
  Шрифты с листа в папке (Footure, Nakadai…) без кириллицы — взяты близкие аналоги.
- Заставка — `SplashScreen.vue` (видео-дым и полоса света из папки, перекодированы в `src/assets/`) + `AsciiLogo.vue`
  (надпись AFTERALL с шипами рисуется на canvas штрихами, как в ascii-art.mp4). Видна минимум 1.3 с при первом запуске.
- Мэтч — сцена с лампой (`MatchOverlay.vue`), пустые состояния — `WireCubes.vue`. Шапка Telegram красится в цвет фона темы (`paintTelegram`).

# База данных

Модели — `backend/app/db/models/`, перечисления — `backend/app/db/enums.py`.

## Принципы
- Локально SQLite, в продакшене PostgreSQL. Схема одна и та же.
- Перечисления хранятся строками, а не нативными enum Postgres — так проще добавлять значения.
- Удаление пользователя каскадно удаляет его профиль, игры, пати, реакции и мэтчи.
  Жалобы и журнал модерации остаются (автор или модератор становится NULL).
- Минимум личных данных: без координат, без обязательных фото, контакты видны только после мэтча.

## Таблицы

### Пользователи
| Таблица | Что хранит |
|---|---|
| `users` | Аккаунт из Telegram: `telegram_id`, имя, язык, роль (user/moderator/admin), дата рождения, возрастная группа, бан |
| `profiles` | Анкета: отображаемое имя, о себе, аватар, микрофон, стиль игры, что ищет, языки, город, часовой пояс, Discord, видимость, репутация; `show_telegram` — показывать ли ник в Telegram мэтчам и участникам пати (по умолчанию нет); `search_age_min/max` — возраст поиска в ленте людей (взаимный, null — до рамки из `domain/age.search_limits`) |
| `user_availability` | Когда человек обычно играет. Из приложения убрано (28.10.2026), таблица оставлена под будущие уведомления «в твоё время» |
| `user_photos` | Фото профиля, до 3, `position` 0 — главное. Пережатый JPEG без EXIF в колонке `data` (грузится отложенно) |

### Игры
| Таблица | Что хранит |
|---|---|
| `games` | Справочник игр: платформы, максимальный размер пати |
| `game_ranks` | Ранги игры; `tier` — порядок, чтобы искать «близкий ранг» |
| `game_roles` | Роли игры (керри, саппорт, снайпер…) |
| `user_games` | Игры в профиле: ранг, ник в игре, основная игра |
| `user_game_roles` | Роли человека в конкретной игре |

### Пати
| Таблица | Что хранит |
|---|---|
| `lobbies` | Заявка «Ищу пати»: игра или «просто провести время», места, требования (ранг, микрофон, стиль, язык), возрастная группа, время начала, срок жизни, статус, ссылка для связи |
| `lobby_members` | Участники и отклики: `pending` → `accepted` / `declined` / `left` / `kicked` |

### Социальное
| Таблица | Что хранит |
|---|---|
| `reactions` | Лайк или пропуск анкеты в ленте; `unmatch` — человек удалил мэтч (ставит только сервер) |
| `matches` | Взаимный интерес; одна запись на пару (`user_a_id < user_b_id`) |
| `blocks` | Блокировки — взаимная невидимость (лента, мэтчи, чаты, сообщения в чатах пати) |

### Чаты
| Таблица | Что хранит |
|---|---|
| `chats` | Переписка: либо `match_id` (личная после мэтча), либо `lobby_id` (общая у пати); создаётся с первым сообщением |
| `chat_messages` | Сообщения (только текст, до 1000 символов); индексы — по чату и по отправителю со временем (лимит частоты) |
| `chat_reads` | До какого сообщения человек прочитал чат — для счётчика непрочитанных; `notified_id` — о каком сообщении последним прислали уведомление в боте (второе не шлём, пока не прочитал) |

### Модерация и репутация
| Таблица | Что хранит |
|---|---|
| `reviews` | Оценка тиммейта после пати (👍/👎 и теги) |
| `rewinds` | Журнал возвратов пропущенных анкет — для лимита Plus (3 за сутки) |
| `subscriptions` | Подписки Plus / Premium на срок (`starts_at`–`ends_at`), откуда (`grant` — выдал админ, `stars` — оплата, позже) и кто выдал. Бесплатный тариф — отсутствие действующей подписки |
| `reports` | Жалобы; причина `minor_safety` разбирается первой. Решения — кнопками в боте, журнал — `moderation_actions` |
| `moderation_actions` | Журнал действий модераторов |

## Возраст
- Группы: `13_15`, `16_17`, `18_plus` (`backend/app/domain/age.py`). Минимальный возраст — константа `MIN_AGE`.
- Пати копирует группу создателя и видна только своей группе.
- Группа меняется с днём рождения — нужна фоновая задача пересчёта (появится вместе с бэкендом).
- Дата рождения задаётся один раз (`PUT /api/me/birth-date`), исправляет только поддержка.
  Если человек младше `MIN_AGE`, ничего не сохраняется.
